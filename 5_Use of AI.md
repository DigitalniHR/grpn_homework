# Use of AI

AI accelerated analysis, implementation and verification; it did not replace an observable model.

```text
manual dependency and join map
→ transparent model in Google Sheets
→ AI-assisted formulas and consistency checks
→ automated tests against the Sheet outputs
→ portable HTML artifact generated from the agreed logic
→ manual reconciliation of key results
```

The Sheet was built before the HTML artifact so every formula and policy decision could be inspected directly. AI then helped test edge cases, compare outputs and implement the interface. The final rating logic remains in editable Settings / `rating_policy.json`, not in an opaque prompt.
